# ASOS Data Analysis

Projeto desenvolvido durante meus estudos de Análise de Dados com Python, com foco em praticar limpeza, transformação, análise e visualização de dados.

A análise utiliza um dataset de produtos da ASOS para explorar informações como:

* preços dos produtos;
* marcas;
* disponibilidade de tamanhos;
* taxa de produtos fora de estoque;
* estimativa de receita perdida;
* comparação entre marcas.

## Tecnologias

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook / Google Colab

## Objetivo

Aplicar conceitos de **Análise Exploratória de Dados (EDA)** em um dataset real, utilizando agrupamentos, criação de métricas e visualizações para identificar padrões relacionados a preço, estoque e marcas.

## Principais análises

* limpeza e tratamento dos dados;
* cálculo de `Stockout Rate`;
* estimativa de `Lost Revenue`;
* análise por marca;
* gráficos para comparação de preço, estoque e impacto financeiro.
